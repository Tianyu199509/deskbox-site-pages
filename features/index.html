DeskBox Features

围绕 Windows 桌面，把文件整理做透

DeskBox 不想把桌面变成另一个复杂系统。它只专注一件事：把桌面上的文件整理清楚——收纳、映射、叠放、格子组、整理桌面。

File Widgets

桌面乱糟糟的文件，终于有地方待了

收纳格子适合处理桌面临时文件，文件夹映射适合把已有目录放到桌面上查看。DeskBox 保留 Windows 原生文件操作习惯，拖入、拖出、重命名、删除、打开和资源管理器定位都按你熟悉的方式工作。

  • 收纳格子默认移动文件到真实收纳目录
  • 文件夹映射不改变原目录位置
  • 叠放与自动归组，支持格内展开或弹窗展开
  • 格子组合并后用标题滚轮或 Ctrl+Tab 切换成员
  • 运行 QuickLook 时空格快速预览文件
Stacks & Groups

叠放与格子组，桌面不再拥挤

同类文件自动叠放；多个格子合并成组，标题滚轮或 Ctrl+Tab 切换成员，桌面从此井井有条。

  • 手动与自动叠放两种模式
  • 格内展开或弹窗展开
  • 格子组合并、拖出与解散
  • 组内成员滚轮或 Ctrl+Tab 切换
Organize

一键整理，公共桌面也照顾到

整理桌面用预览卡逐文件勾选，重新扫描保留选择，可中断续作；还可选择纳入公共桌面。

  • 预览卡逐文件勾选
  • 来源可选公共桌面
  • 被中断的整理可恢复
  • 下载稳定后自动整理新文件
Settings

设置按能力分区，性能与资源独立可调

设置现为常规（含性能与资源）、外观、胶囊模式、文件格子、功能格子、快捷与交互等分区，按需加载、都能被搜索命中。

常规设置

语言、开机自启、新用户引导和性能与资源选项。

外观设置

背景透明度、文字大小、标题样式、圆角、主题和动画。

文件格子设置

默认收纳路径、文件显示、快捷方式箭头和列表细节。

功能格子设置

待办、随记、音乐等内容格子的开关和显示细节。

胶囊模式

收起样式、收起后显示内容、悬停展开等胶囊行为。

快捷与交互

全局快捷键、格子层级、Win+D 行为与交互细节。

Principles

几个不会轻易改变的方向

原生优先

优先使用 WinUI 3、Windows App SDK 和系统能力，减少不必要的第三方依赖。

本地优先

用户文件、待办、随记和缓存都留在本机，不做云同步前置假设。

克制扩展

格子可以越来越多，但每个格子都要解决一个明确桌面场景。

轻量常驻

尽量控制后台资源，让 DeskBox 成为桌面的一层能力，而不是新的负担。

从最新版本开始体验

推荐 Windows 11。Windows 10 会自动降级部分材质与动画效果，核心功能按兼容基线验证。
