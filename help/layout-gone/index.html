重启、换显示器后格子不见了或位置乱了

更新于 2026-11-24

本页内容: 常见问题

格子布局按显示器硬件标识和屏幕组合分别记忆：单屏、双屏、接扩展坞等每一种组合各自保存一套布局。插拔或更换显示器相当于切换到新组合，首次会自动生成合理布局——格子不是丢了，多半只是换到了别的位置或别的屏幕上。

操作步骤

  1. 1 打开 设置 → 窗口与交互 → 显示器：在顶部交互式显示器示意图中查看各块屏幕排列与格子清单，点击识别让对应显示器闪烁确认。
  2. 2 集中整理：用 「全部移到此显示器」 把格子一次移到当前屏；移动后可撤销，拔屏后撤销依然有效；「新格子的显示器」也可指定新增格子默认落点。
  3. 3 固定布局：可直接在显示器视图里逐个修改「各格子所在显示器」，或在单个格子/格子组标题栏右键「移到显示器」锁定某块物理屏，插拔不再乱跑。
  4. 4 显示器连接与缩放策略：下方展开可设定 「屏幕尺寸或缩放变化时」（保持尺寸或等比缩放）、「显示器断开时」（重排到其余屏幕或收起为胶囊，插回原屏恢复）与 「重新校准布局」。
注意 检测到虚拟显示器（1.6.0 提醒）： 当你使用 Parsec、Sunshine、远程虚拟屏或虚拟扩展器并把主显示器设为虚拟适配器时，部分显卡驱动会导致网格叠放异常、闪烁甚至卡顿闪退。出现「检测到虚拟显示器」横幅时，建议在 Windows 显示设置中将物理显示器设为主显示器再试。

分辨率或 DPI 缩放变更时，「屏幕尺寸或缩放变化时」会弹性重算安全范围，防止格子飞出屏幕可视区外。

锁屏、休眠唤醒后格子短暂消失属正常：布局跟随显示器拓扑重连记忆，稍候即自动恢复；若唤醒后位置不对，点开 设置 → 窗口与交互 → 显示器 使用「重新校准布局」或核对列表。

配置损坏也有兜底：1.5.9 起，配置被清空或损坏且存在可用备份时，启动会弹出「从备份恢复 / 全新开始」的一次性提议，选择恢复即可找回布局与设置。

注意 「从备份恢复」提议只出现一次；没赶上也不必担心，设置 → 数据与备份 里仍可手动恢复备份。

常见问题

重启后格子不见了？ +

布局按显示器组合分别记忆。到 设置 → 窗口与交互 → 显示器 查看各屏的格子清单，用「全部移到此显示器」或「重新校准布局」集中找回。

换了显示器或连接远程桌面后，格子位置全乱了？ +

新的显示器组合首次会自动生成一套布局。给常用格子右键「移到显示器」绑定到物理屏幕，或在 设置 → 窗口与交互 → 显示器 开启「屏幕尺寸或缩放变化时」适配策略。

锁屏回来或休眠几天后，格子都没了？ +

布局跟随显示器拓扑记忆，唤醒后会自动恢复；未恢复时到 设置 → 窗口与交互 → 显示器 点击「重新校准布局」或检查该组合下的格子清单。

拔掉笔记本的外接屏后，格子去哪了？ +

拔屏后格子会按「显示器断开时」策略弹性重排到剩余屏幕或收起为胶囊；插回原屏自动恢复原位。

提示「检测到虚拟显示器」，或者开虚拟屏后格子卡死在角落怎么办？ +

若主显示器运行在 Parsec/Sunshine 等虚拟显示适配器上，部分环境会出现窗口叠加或稳定问题——请在 Windows 显示设置里切回实体物理显示器为主显示器，再点击设置里的「重新校准布局」。

配置损坏，格子全没了怎么办？ +

启动若弹「从备份恢复」提议直接点恢复；错过提议也可到 设置 → 数据与备份 手动还原快照或 ZIP 备份。
