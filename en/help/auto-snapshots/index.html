How do I configure automatic snapshots?

Updated · 2026-09-08

Since 1.5.0 DeskBox takes automatic data snapshots: local snapshots of settings and app data on a schedule, used for failure recovery; a snapshot is also taken before every restore so you can undo.

设置路径SettingsData & backup

Related settings

Settings & content backup

Backs up settings, widgets, notes, tasks and attachment copies; files inside file widgets are not included.

Automatic backup / Backup interval

Scheduled local snapshots, from every 5 minutes to every 5 days (daily by default).

Snapshots to keep

When the limit is reached, the oldest snapshots are deleted (3–30, 7 by default).

Backup folder

Where automatic snapshots are saved; empty uses the default recovery folder, with automatic fallback and a notice.

Export backup / Restore backup

ZIP backups with SHA-256 integrity checks; restores are validated with a content preview first.

Local snapshots

Used for failure recovery; a pre-restore snapshot lets you undo a restore.
