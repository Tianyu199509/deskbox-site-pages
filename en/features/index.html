DeskBox Features

Focused file organization for the Windows desktop

DeskBox does not try to turn your desktop into another complex system. It focuses on one thing: keeping desktop files organized — collect, map, stack, group, organize.

File Widgets

Bring desktop files under control

Collect widgets are for temporary desktop files, while folder mapping lets existing directories stay visible on the desktop. DeskBox keeps native Windows file behavior for drag, rename, delete, open and Explorer location.

  • Collect widgets move files into a real storage folder
  • Folder mapping keeps the original folder location
  • Stacking with auto-grouping, inline or popover expansion
  • Widget groups switch members with the title wheel or Ctrl+Tab
  • QuickLook space-bar preview when QuickLook is running
Stacks & Groups

Stacks and groups keep the desktop tidy

Similar files stack automatically; merge widgets into groups and switch members with the title wheel or Ctrl+Tab.

  • Manual and automatic stacking modes
  • Inline or popover expansion
  • Group merge, detach and dissolve
  • Switch members via title wheel or Ctrl+Tab
Organize

One-click organize, Public Desktop included

Organize Desktop previews every file for per-file selection, keeps selections across re-scans and supports resumable runs; the shared Public Desktop can be included.

  • Preview card with per-file selection
  • Optional Public Desktop source
  • Interrupted runs are resumable
  • New files organized automatically once downloads settle
Settings

Settings organized by capability, with a dedicated performance section

Settings now span General (with performance and resources), Appearance, Capsule mode, File widgets, Feature widgets and Shortcuts sections, created on demand and searchable throughout.

General

Language, startup, onboarding and performance/resource options.

Appearance

Opacity, text size, title style, corner radius, theme and animations.

File widgets

Default storage path, file display, shortcut arrows and list details.

Feature widgets

Switches and display options for todo, quick capture, music and other content widgets.

Capsule mode

Collapsed style, collapsed content, hover-to-expand and other capsule behaviors.

Shortcuts & interaction

Global hotkeys, widget layers, Win+D behavior and interaction details.

Principles

A few directions that will not change lightly

Native first

Prioritize WinUI 3, Windows App SDK and system capabilities while reducing unnecessary third-party dependencies.

Local first

Files, widget settings and caches stay on your device without assuming cloud sync.

Restrained expansion

More widgets can arrive, but every widget should solve a clear desktop scenario.

Lightweight resident

Keep background resource usage controlled so DeskBox becomes a desktop layer, not another burden.

Start with the latest version

Windows 11 is recommended. Windows 10 degrades some materials and animations gracefully; core features are validated against the compatibility baseline.
