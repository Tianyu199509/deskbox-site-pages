文字大小与图标大小

更新于 2026-11-24

本页内容: 常见问题相关设置

看不清或觉得太挤？文字大小、显示密度、文件格子图标大小与待办/随记的正文字号都可以分别调节，改完立即生效。

设置 › 外观

1.6.0 起，“文件格子图标大小与横纵间距”已从外观迁入 设置 → 文件与整理 → 文件与图标显示 → 图标与排版间距（也可在某个文件格子空白处右键 →「查看 → 图标大小」单独覆盖）。

待办和随记还有各自的独立正文字号（在 设置 → 功能格子 → 待办 / 随记 → 正文字号缩放）：在随记上按住 Ctrl 滚动滚轮也能随手缩放。

常见问题

4K 或高分屏缩放下字体太小怎么办？ +

先在 设置 → 外观 → 显示密度 调大「文字大小」或切换「整体密度」；待办、随记还有独立「正文字号缩放」，随记上 Ctrl+滚轮可即时缩放。整体仍偏小时，检查 Windows 的显示缩放设置。

字体可以换成别的吗？ +

目前提供字号与显示密度调节，不提供更换系统字体的设置（时光格子支持挑选时钟字体风格）。

图标和文字能分开调吗？ +

能。「文字大小」在 设置 → 外观 → 显示密度；「图标大小」则在 设置 → 文件与整理 → 文件与图标显示 → 图标与排版间距，两者完全独立。

随记的字号怎么单独调？ +

在随记上按住 Ctrl 滚动滚轮随手缩放；或到 设置 → 功能格子 → 随记 → 正文字号缩放 精确调整「列表文字大小 / 内容文字大小」。

相关设置

设置项 说明
文字大小 位于 设置 → 外观 → 显示密度：全局调节格子与界面文字大小。
显示密度 / 整体密度 位于 设置 → 外观 → 显示密度：控制整体卡片密度与内边距。
图标大小 / 横向间距 / 纵向间距 位于 设置 → 文件与整理 → 文件与图标显示 → 图标与排版间距：调节文件格子图标尺寸与文件名宽度/行数。
格子标题图标 位于 设置 → 外观 → 应用主题：控制格子标题栏前是否显示图标（单格标题样式请右键格子 → 格子样式 → 标题样式）。
列表文字大小 / 内容文字大小 分别位于 设置 → 功能格子 → 待办 与 随记 下的「正文字号缩放」，一个管列表文字，一个管内容正文。
