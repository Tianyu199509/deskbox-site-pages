让 Windows 桌面井然有序

以本地文件夹为基础的桌面整理工具。收纳文件、映射目录、按需展开，与 Windows 原生体验保持一致。

DeskBox · 桌面全景

支持云母与亚克力材质，并为每种显示器组合分别保存布局。

文件管理

整理桌面，而不改变你使用 Windows 的方式

每个文件格子都对应一个标准的 Windows 文件夹。文件始终可在文件资源管理器中访问，DeskBox 不会替换系统桌面，也不会接管你的文件。

文件格子与文件夹映射

文件夹，原样呈现在桌面

新建文件格子以收纳桌面上的截图、文档与安装包，或将现有目录映射到桌面，无需复制或移动原始文件。所有更改与文件资源管理器实时同步。

  • 保留 Windows 原生右键菜单与拖放行为
  • 整理桌面前提供逐项预览，下载完成后再执行归档
  • 卸载 DeskBox 后，所有文件仍保留在原位置

    多显示器

    更换显示器，布局依然如故

    搜索与 AI

    快速找到所需内容，按需创建小组件

    在文件管理之上，DeskBox 提供全局搜索与 AI 小组件，让桌面随工作方式扩展。

    AI 小组件

    用一句话描述，即可生成小组件

    以自然语言描述所需功能，AI 将生成可交互的桌面小组件。生成的小组件与内置格子外观一致，同样支持缩放与胶囊模式。
