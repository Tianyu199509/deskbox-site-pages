DeskBox v1.2.0

A desktop organizer that keeps getting better

DeskBox 1.2.0 unified file widgets and feature widgets on one WidgetShell architecture, redesigned the todo card list and detail view, upgraded quick capture and music controls, and added the weather widget.

Why v1.2.0

Not just more features, but a better daily desktop experience

1.2.0 put file and feature widgets on one shared architecture, upgraded todos, quick capture and music across the board, and introduced the weather widget.

01

Todo rebuilt

Card-based task list with in-widget detail page. 8 color markers, drag sorting, due dates, reminders, recurrence, attachments, and batch actions.

02

Quick capture redesign

Notes-and-images tool with paper styles, image add/replace/preview, pinned lists, and batch actions. Focused editor is more spacious.

03

New weather widget

Auto-location or manual city search with hourly and weekly forecasts, sunrise/sunset, UV index, precipitation, humidity, wind, and pressure.

04

Music simplified and file drag-in

Music removes spectrum in favor of centered album-art, compact controls and title marquee. File widget drag-in is smoother.

The direction stays restrained

01

Prefer native Windows capabilities whenever they are enough.

02

Do not turn the desktop into another complex system.

03

Files, todos, notes, settings and thumbnail caches stay local first.

04

More widgets can arrive, but each should solve a clear desktop scenario.

Start with DeskBox v1.2.0

If desktop files, short-lived tasks, copied content and music windows interrupt your flow, this release is ready to try as a daily utility.
