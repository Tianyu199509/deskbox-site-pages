隐私政策

本地优先，默认私密。

DeskBox 隐私政策：坚持本地优先设计（适用于 Windows 10 与 Windows 11），桌面文件、格子布局、剪贴板历史（本机 DPAPI 加密）、待办事项与随记全部保存在你的电脑本地，无需注册账号、零应用遥测、无第三方广告追踪。

适用于 DeskBox Windows 客户端（直装版与微软商店版）及 deskbox.fun 官网 更新日期：2026-11-23

1. 本地优先，零遥测

DeskBox 桌面客户端无需注册或登录账号，不采集应用使用遥测、崩溃行为画像或广告标识符。

你的桌面文件始终是普通的 Windows 本地文件；格子布局、待办事项、随记内容、剪贴板历史（敏感凭据自动经 Windows 本机 DPAPI 静态加密）、时光壁纸、自定义组件与缩略图缓存全部保存在你的电脑本地：

  • 直装版（Direct）：%LocalAppData%\DeskBox
  • 微软商店版（1.6.0 起）：%UserProfile%\DeskBox\.appdata（应用重置或重装不会清空用户数据）

2. 有限且透明的联网场景（均按需或由你主动触发）

除以下明确场景外，DeskBox 不会主动连接外部网络：

  • 检查更新与更新日志（直装版）：访问 https://deskbox.fun/update/stable.json（必要时回退 GitHub Releases）检查新版并校验安装包 SHA-256。
  • 天气与同步歌词（仅在启用对应格子时）：按你设置的城市或可选定位请求天气服务（MSN Weather / Open-Meteo），以及按需通过 LRCLIB 获取同步歌词。
  • WebDAV 云备份（默认关闭）：仅在你主动配置后，将备份快照上传至你自己指定的 WebDAV 服务器；密码保存在本机 Windows 凭据管理器，不经过 DeskBox 服务器。
  • 自定义组件、格子工坊与 AI（由你触发）：自有 API（BYOK）直接从本机请求你配置的模型接口；自定义组件联网源受按组件独立授权门禁管控；官方远程组件目录与提示词元数据（deskbox.fun/widgets/）强制通过离线 ECDSA P-256 签名校验。
  • 剪贴板网页标题自动抓取（默认关闭）：仅在手动开启后生效，且自动跳过局域网/本机及一次性登录、验证、签名与退订链接。

3. 系统能力与本机权限说明

DeskBox 仅在你使用对应功能时于本机调用系统能力：

  • 位置权限（可选）：仅用于在天气格子中选择自动定位城市。
  • 无线电 / 设备控制（可选）：仅在自定义组件中主动点击 Wi-Fi / 蓝牙快捷开关时生效。
  • 离线图片 OCR：完全基于 Windows 本机 OCR 能力运行，截图与识别文字不会上传至任何服务器。

4. 主动反馈与诊断包

当你主动通过应用内「发送反馈」或官网反馈社区（deskbox.fun/feedback/）提交问题或建议时，服务端会保存反馈正文、应用版本、系统信息、渠道、语言、本机随机匿名标识（用于查看「我的反馈」与多轮跟帖回复）以及加盐 IP 哈希（仅用于防刷限流）。

提交 Bug 时可自主选择是否附带诊断包。诊断包在上传前已做结构化隐私过滤，不包含 settings.json、文件清单、待办/随记/剪贴板内容或个人密钥；服务端保存的诊断包会在 90 天后自动清理。

5. 官网访问统计与你的数据控制权

deskbox.fun 官网仅使用无 Cookie 的第一方基础访问与下载统计，不接入第三方广告追踪脚本。你随时可以导出备份，或在退出 DeskBox 后删除上述本地数据目录彻底清除全部本机数据。

6. 联系与反馈删除

如对本隐私政策有疑问，或希望删除你曾提交的公开反馈记录，可通过 GitHub Issues 或项目仓库主页公布的维护者联系方式与我们取得联系。
