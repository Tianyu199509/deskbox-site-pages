全局搜索（Alt+D）与 Everything

更新于 2026-11-24

本页内容: 常见问题相关设置

1.6.0 将原独立「搜索」格子统一收敛为全局搜索弹窗：新用户安装即默认开启 `Alt+D` 全局快捷键（也可从托盘右键「全局搜索」或新手引导第 3 步唤起），一框检索本机文件、文件夹、应用、桌面小组件、待办、随记、剪贴板历史、DeskBox 设置项与快捷指令，还可直接计算、快速新建与跳转网页。

设置 › 全局搜索

操作步骤

  1. 1 按 Alt+D 唤起全局搜索弹窗（可在 设置 → 全局搜索 → 搜索快捷键 自定义快捷键）。
  2. 2 启用本机文件搜索（必须由你主动授权）：到 设置 → 全局搜索 →「Everything 文件搜索」开启开关——该开关默认关闭。
  3. 3 确认电脑上已安装并运行 Everything：推荐使用 Everything 安装版（会随系统自启）；便携版需每次手动打开；Everything Lite（精简版）不包含 IPC 服务，无法被 DeskBox 连接。

14 类统一内容范围与结果标签管理： 弹窗顶部标签栏与「搜索范围」完全一体化。通过设置里的「搜索内容与分类标签」，或直接点击弹窗标签栏最右侧的漏斗按钮打开「分类与搜索范围」浮窗，即可拖拽调整 14 个分类顺序（文件、图片、应用、设置、文档、文件夹、待办、随记、剪贴板、小组件、快捷指令、视频、音乐、压缩包），并用「搜」和「Tab」芯片分别控制是否参与检索或固定为顶部快捷标签页（默认固定为「全部 / 文件 / 图片」）。

行内精确前缀与锁定范围： 输入带冒号的前缀即可锁定在单一分类内筛选，包括 app: / 应用:、file: / 文件:、folder: / 文件夹:、img: / 图片:、doc: / 文档:、video: / 视频:、music: / 音乐:、archive: / 压缩包:、todo: / 待办:、note: / 随记:、clip: / 剪贴板:、widget: / 小组件:、set: / 设置: 与 > / 命令:（快捷指令面板）；输入 + 待办 或 ; 随记 / ~ 随记（也支持 Ctrl+T / Ctrl+N）无需切窗口就能直接创建待办或随记。

提示 计算器与网页兜底：输入算式实时算出结果并回车复制；输入网址直接跳转，关键词前加 ? 强制走默认搜索引擎（Bing、Google、百度、DuckDuckGo 或自定义 URL 模板）；在 Everything 开关下还可按需开启「Everything 搜索语法」（默认关闭）。

支持拼音首字母匹配： 在搜索随记与 DeskBox 设置项时已支持拼音首字母检索（如输入 xmzbhz 可匹配「项目周报汇总」，输入拼音也可直达常见设置项），中英文混搜更省事。

细节预览、排序栏与窗口记忆： 按 Ctrl+D 实时开关右侧详情预览侧栏（支持图片、视频封面、PDF 首页、文档及纯文本预览）；按下 Ctrl+K 可唤起次要动作面板（打开位置、复制路径、以管理员运行、转入待办/随记、开关详情侧栏及开关「列表排序栏」）；选中文件结果按空格（或 Ctrl+Space）可联动 QuickLook 预览。1.6.0 还支持手拖四边调整弹窗尺寸并自动记忆，列表排序栏（名称/类型/大小/创建时间）默认关闭，重度用户可在 设置 → 全局搜索 → 结果视图与排序 开启。

搜索弹窗内的「推荐应用」支持编辑模式：可新建、重命名、解散应用文件夹，移入移出、多选拖拽批量归组与批量隐藏恢复，也能直接从 设置 → 全局搜索 关闭推荐区域或「推荐应用图标动效」。

注意 为什么搜不到本机文件？DeskBox 不额外维护第二套索引库，全权依赖 Everything 本机只读 IPC：请检查是否安装并运行了标准安装版/便携版 Everything（Lite 版无法连接），并在 设置 → 全局搜索 开启了「Everything 文件搜索」开关（Microsoft Store 版因渠道规范不展示外部下载按钮，可自行从 voidtools 官网获取 Everything）。

常见问题

Everything 必须开着吗？DeskBox 自带文件索引吗？ +

是的。为避免重复扫盘占用双份内存，DeskBox 1.6.0 专注通过只读 IPC 读取本地 Everything 索引，自身不另建后台文件索引库；只搜应用、设置、待办、随记和剪贴板时即使不装 Everything 也能照常使用。

装了 Everything 为什么结果里还是没有文件？ +

常见原因有两个：① Everything Lite（精简版）不支持 IPC，请更换标准安装版或完整便携版并确认托盘正在运行；② 设置 → 全局搜索 →「Everything 文件搜索」开关默认关闭，需手动开启授权连接。

支持拼音搜索吗？ +

支持对随记与 DeskBox 设置项做拼音首字母匹配（如首字母缩写直接定位待查笔记与设置）；本地文件检索遵循 Everything 的关键词与可选语法匹配。

列表排序栏和右侧详情侧栏怎么打开？ +

右侧详情侧栏默认开启，可用 Ctrl+D 随时切换；文件「列表排序栏」（名称/类型/大小/创建时间）默认关闭，可按 Ctrl+K 在更多动作面板里切换，或在 设置 → 全局搜索 → 结果视图与排序 开启。

搜索框能当计算器和快捷记录用吗？ +

能。输入算式实时算出结果并回车复制；输入 + 买牛奶 或 ; 记一条想法（也可按 Ctrl+T / Ctrl+N）直接保存为待办或随记。

怎么隐藏或重排搜索结果顶部的分类标签，或缩小搜索范围？ +

点击搜索框顶部标签栏最右侧的漏斗按钮打开「分类与搜索范围」浮窗（或进入 设置 → 全局搜索 → 搜索内容与分类标签），拖拽排序并分别勾选每类的「搜」或「Tab」开关即可。

以前的桌面独立「搜索」格子去哪了？ +

1.6.0 起独立桌面搜索格子已收敛为统一的 Alt+D 全局搜索弹窗，不再单独占用桌面空间；原有历史偏好会自动并入全局搜索设置。

相关设置

设置项 说明
搜索快捷键 默认 Alt+D（新安装自动启用）；支持自定义热键及一键关闭。
推荐内容 / 推荐应用图标动效 控制空输入时是否展示推荐应用面板，以及应用图标入场动效。
Everything 文件搜索 / Everything 搜索语法 默认关闭，需手动授权开启；展开可查看连接状态、自动检测、手动指定 Everything.exe 与启用 Everything 高级语法。
网址访问与网页搜索 / 默认网页搜索引擎 控制直达网址与网页搜索兜底；可选 Bing、Google、百度、DuckDuckGo 或自定义 URL 模板。
搜索内容与分类标签 / 快捷计算 对 14 类搜索范围统一排序，分别勾选是否参与检索（搜）或置顶标签栏（Tab），支持一键恢复默认；下方可开关行内计算器。
快捷新建 控制是否在搜索框中通过 + / ; / ~ 等前缀快速创建待办与随记，以及默认目标与保存提示。
结果视图与排序 / 列表排序栏 设置默认结果分类、分类筛选栏显隐、默认详情侧栏、开启「列表排序栏」（默认关闭）以及默认排序方式（相关度/日期/名称/大小）。
