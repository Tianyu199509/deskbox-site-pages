Capsule Mode

不用时收成一颗胶囊，要用时一触即开

任何格子都能收起成紧凑的胶囊，悬停或点击即可展开。常用内容留在桌面，空闲时不占地方；多个胶囊还可以组成胶囊栏，整体移动和排序。

  • 收起后只显示图标与标题，或关键信息摘要
  • 点击展开，或开启悬停自动展开
  • 展开方向自动适配摆放位置

Version 1.5.0

桌面整理工具 正在变得更好用

DeskBox v1.5.0：功能与可靠性更新：新增数据自动快照备份、整理桌面重设计（支持公共桌面）、格子内文件夹快捷方式导航、高分辨率 Shell 图标与独立字号设置，并继续降低内存占用；直发包改为 Full Native AOT 构建，自带匹配的 Windows App Runtime。

查看最新更新日志
01

数据自动快照备份

可配置备份计划（5 分钟到 5 天）、保留 3~30 份快照、支持自定义目录；目录不可用时自动降级并通知。

02

整理桌面重设计，支持公共桌面

全新桌面预览卡、逐文件勾选、重新扫描保留选择、可中断续作的恢复流程，并可选择纳入所有账户共享的公共桌面。

03

文件夹快捷方式就地导航

指向格子自身收纳目录内的快捷方式直接在格子内展开，不再跳转资源管理器。

04

更清晰、更正确的图标

文件、文件夹和 `desktop.ini` 自定义图标改用 256px Shell 图标并保留叠加层；网址快捷方式图标（含 Steam 封面）由 Shell 解析。

Widgets

桌面上真正会用到的几个格子

收纳、映射、叠放、格子组、整理桌面——文件整理需要的一切都在桌面这个最熟悉的位置。

文件格子

收纳桌面文件，也能映射已有文件夹。支持列表/图标视图、拖入拖出和原生文件操作。

叠放与格子组

同类文件自动叠放；多个格子合并成组，标题滚轮或 Ctrl+Tab 切换成员。

整理桌面

预览卡逐文件勾选，支持公共桌面与可中断续作的整理流程。

Native First

尽量像 Windows 自己长出来的工具

DeskBox 优先使用 WinUI 3、Windows App SDK 和系统能力。能用原生控件解决的地方，就尽量不引入重型第三方方案。
