支持 Windows 10 吗？

最后更新 · 2026-09-06

支持 Windows 10 21H2（build 19044）及以上。自 1.4.4 起 Windows App SDK 2.4 的最低系统要求即为 Windows 10 21H2（Build 19044），低于此版本会提示不受支持；Windows 10 上云母材质、系统级圆角和部分动画会按系统能力自动降级，核心功能按兼容基线验证。

Windows 11 22H2 及以上可以获得完整视觉体验，也是推荐配置。
