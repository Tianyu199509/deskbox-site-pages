How do in-app updates work?

Updated 2026-11-24

On this page: Frequently asked questionsRelated settings

The Direct build's in-app updater (shipped with 1.5.9+) checks automatically once a day at a fixed anchor time, backing off ~2 hours on failures.

When a release is found, it downloads in the background (automatically skipping metered connections). Once ready, a toast notification, tray entry, and About badge invite you to install when convenient.

After you confirm, DeskBox saves your settings and creates a restore point before launching the updater helper — keeping your current install intact if anything fails. Turn on "Show release notes after update" to see what's new right after upgrading.

Browse full version history anytime in Release notes; "Auto-download updates" and "Show update notifications" are two independent switches you can toggle separately.

The Microsoft Store edition updates silently through Microsoft Store instead and hides Direct-only auto-download toggles.

Settings › About › App updates

Frequently asked questions

The update failed — what should I do? +

Retry or check connectivity; if GitHub is slow or blocked, grab the latest installer directly from the download page mirrors. A pre-update restore point keeps your existing version intact if installation doesn't finish (see "Update fails or the download is slow").

Do updates install automatically, or do I confirm them? +

Checking and optional "Auto-download updates" happen automatically, while installing waits for your confirmation.

Will it eat my mobile-hotspot data? +

No. Auto-download skips metered connections automatically.

Where can I read what each past version changed? +

Click Release notes inside Settings → About → App updates to browse the full history.

Related settings

Setting Description
Auto check (Direct) Checks once a day at a fixed anchor time; failures back off ~2 hours before retrying.
Auto-download updates (Direct) Silently downloads releases in the background on unmetered networks; toggleable independently.
Show update notifications (Direct) Shows a Toast and About status badge when an update is ready; independent from Auto-download.
Show release notes after update Automatically opens the release-notes view on first launch after updating.
Update details / One-click update / Release notes Check manually, install ready updates, inspect progress or manual download link, and browse all version history.
