Global Search (Alt+D) and Everything

Updated 2026-11-24

On this page: Frequently asked questionsRelated settings

In 1.6.0, the old standalone Search widget converges into the Global Search popup: new installs enable the `Alt+D` global hotkey out of the box (also reachable from Tray right-click → "Global search" or Onboarding Step 3), letting you search local files, folders, apps, widgets, todos, notes, clipboard history, DeskBox settings, and commands from one place.

Settings › Global search

Steps

  1. 1 Press Alt+D to summon Global Search (customize or toggle under Settings → Global search → Search hotkey).
  2. 2 Opt in to local file search: expand Settings → Global search → "Everything file search" and enable permission (off by default).
  3. 3 Make sure Everything is installed and running: the installer edition is recommended (starts with Windows), the portable edition works if started manually, and Everything Lite cannot connect because it lacks local IPC.

14 Unified Categories & Tab Management: Search scope and tab pills are managed from one place — either "Search Content & Category Tabs" in Settings or the funnel button on the right end of the popup tab bar ("Categories & Search Scope"). Drag to reorder all 14 categories (Files, Images, Apps, Settings, Documents, Folders, Todos, Notes, Clipboard, Widgets, Commands, Videos, Music, Archives) and toggle "Search" or "Tab" chips independently (default pinned tabs: All, Files, Images).

Inline Scope Prefixes & Quick Create: Lock searches to a single scope using app:, file:, folder:/dir:, img:/pic:, doc:, video:, music:/audio:, archive:/zip:, todo:, note:, clip:/clipboard:, widget:, set:/settings:, or >/cmd: (Commands palette); type + todo or ; note / ~ note (or press Ctrl+T / Ctrl+N) to create tasks and notes inline without opening another window.

Tip Inline Calculator & Web Fallback: type math expressions to copy answers on Enter; type a URL to open it directly, or prefix keywords with ? for your chosen engine (Bing, Google, Baidu, DuckDuckGo, or custom template); optionally enable "Allow Everything search syntax" (off by default).

Pinyin Initials Search: Notes and DeskBox settings support Pinyin initial matching (e.g. xmzbhz matches Chinese notes or settings), speeding up mixed-language queries.

Details Sidebar, Column Sort Bar & Window Memory: Press Ctrl+D to toggle the right details preview sidebar (images, video thumbnails, PDF first pages, docs, notes); press Ctrl+K for the secondary action palette (Run as admin, Open location, Copy path, Convert to Todo/Note, Toggle Details, and Show column sort bar); press Space (or Ctrl+Space) on a file row for QuickLook preview. Drag any window edge to resize with saved dimensions; the column sort bar (Name / Type / Size / Created) stays hidden by default and can be enabled under Results view & sorting or via Ctrl+K.

Recommended apps in Global Search support Edit Mode: create, rename, and dissolve app folders, drag multi-selections into groups, and batch hide/restore recommendations, or disable recommendations / "App icon animation" under Settings → Global search.

Note Seeing no file results? DeskBox never maintains a duplicate background file index — it queries Everything read-only over local IPC. Check that a standard/portable (non-Lite) Everything instance is running and that "Allow DeskBox to query Everything" is enabled under Settings → Global search (Microsoft Store builds omit external Everything download links).

Frequently asked questions

Does Everything have to be running? +

Yes for local whole-disk file results. DeskBox 1.6.0 reads Everything's index over zero-dependency local IPC instead of running a second background file indexer; Apps, Settings, Todos, Notes, Clipboard, Calculator, and Commands still work without Everything.

I installed Everything, so why do searches still show no files? +

Two common traps: (1) Everything Lite lacks IPC and cannot connect — install standard or portable Everything and ensure it is running; (2) "Everything file search" under Settings → Global search is off by default and must be toggled on.

Is pinyin search supported? +

Yes for Notes (Quick Capture) and DeskBox settings, where Pinyin initials resolve matching entries quickly; file searches pass keywords directly to Everything.

How do I toggle the column sort bar or the right details sidebar? +

Press Ctrl+D for the details sidebar; the file column sort bar (Name, Type, Size, Created) is hidden by default and can be toggled with Ctrl+K → Show column sort bar or under Settings → Global search → Results view & sorting.

Can the search box work as a calculator and quick note creator? +

Yes. Math expressions evaluate live and copy on Enter; + task and ; note (or Ctrl+T / Ctrl+N) save directly to Todo or Quick Capture.

How do I customize top result tabs or exclude a category? +

Click the funnel button on the right of the Global Search tab strip ("Categories & Search Scope") or open Settings → Global search → Search Content & Category Tabs to reorder categories and toggle Search / Tab chips.

Where did the standalone desktop Search widget go? +

In 1.6.0, the standalone desktop Search widget retired into the unified Alt+D Global Search popup, carrying your preferences forward automatically.

Related settings

Setting Description
Search hotkey Defaults to Alt+D on new installs; customize or toggle anytime.
Recommendations / App icon animation Toggle recommended apps shown on an empty query and their icon entrance motion.
Everything file search / Allow Everything search syntax Opt-in IPC bridge (off by default); auto-detects or browses Everything.exe and toggles advanced Everything syntax.
Direct URLs and web search / Default web search engine Configure direct URL navigation and Bing, Google, Baidu, DuckDuckGo, or custom web search fallback.
Search Content & Category Tabs / Inline calculator Reorder all 14 categories, toggle Search/Tab chips or restore defaults, and toggle the inline math evaluator.
Quick create Configure +, ;, ~ quick creation for Todos and Quick Capture notes, visibility mode, default target, and confirmation banner.
Results view & sorting / Show column sort bar Set default result tab, filter bar visibility, Ctrl+D details sidebar default, column sort bar toggle (off by default), and default sort.
